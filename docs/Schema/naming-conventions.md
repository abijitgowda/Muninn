# Naming conventions

Consistent filenames are the foundation of working wikilinks. Follow these rules.

## Slug rules

- **Title Case for display**, but the filename is the natural-language title (no kebab, no snake).
  - File: `Reinforcement Learning from Human Feedback.md`
  - Link: `[[Reinforcement Learning from Human Feedback]]`
- Use canonical full names. Disambiguate with parentheses when needed.
  - `Jordan Peterson (psychologist).md` not `Jordan Peterson.md` if there's a Jordan Peterson basketball player too.
- ASCII only. Replace accents (`é → e`) unless the canonical spelling demands them. Document exceptions in this file.
- No leading articles for sorting: `The Selfish Gene` is fine because Obsidian sorts smart, but prefer noun-first when natural (`Selfish Gene, The` — only if you really want).
- Acronyms: spell out on first reference, then use the acronym page if it's well-known.
  - `Reinforcement Learning from Human Feedback.md` with alias `aliases: [RLHF]` in frontmatter.

## Folder routing (where to file a new page)

| Page kind | Folder | Notes |
|---|---|---|
| `concept` | `Wiki/Concepts/` | Ideas, methods, theories, patterns |
| `person` | `Wiki/Entities/People/` | One file per individual |
| `org` | `Wiki/Entities/Orgs/` | Companies, universities, labs |
| `topic` | `Wiki/Topics/` | Cross-cutting themes that span many concepts |
| `project` | `Wiki/Projects/` | Things you're actively working on |
| `log-day` | `Wiki/Logs/` | Filename `YYYY-MM-DD.md` |
| `source-summary` | `Wiki/sources/` | Auto-created during ingest; filename `YYYY-MM-DD-<source>-<slug>.md` |

If you genuinely don't know where a page belongs, file it under `Wiki/_misc/` and `llm-wiki-maintain` will promote it during the weekly sweep.

## Wikilinks

- Prefer **canonical-name wikilinks**: `[[Jensen Huang]]`.
- Use `|alias` syntax sparingly, only when the rendered text genuinely needs to differ: `[[Reinforcement Learning from Human Feedback|RLHF]]`.
- For section links: `[[Page#Heading]]`.
- For embeds (rare): `![[Page]]`.

## Tags

- Hierarchical with `/`: `ai/ml`, `ai/alignment`, `productivity/notes`.
- Lowercase only.
- No spaces (`ai/large-language-models`, not `ai/large language models`).
- Maintain a controlled vocabulary in `Schema/tag-taxonomy.md` (created lazily when needed).

## Source-summary filenames

Auto-generated by the ingest pipeline. Format:

```
YYYY-MM-DD-<source-type>-<slug>.md

# examples
2026-05-22-browser-history-ai-knowledge-architecture.md
2026-05-22-x-1761234567890123456.md
2026-05-22-url-anthropic-claude-4-7-launch.md
2026-05-22-inbox-meeting-notes.md
```

The `<source-type>` segment is the connector `type:` from `wiki.yaml` (underscores → hyphens). It is intentionally not the per-config `name:` — that way two X accounts (or two browser histories) produce uniform slugs and the differentiation lives in the source-summary's `source_name:` frontmatter.

Slug derivation:
- For URLs: last meaningful path segment, lowercased, max 60 chars.
- For X posts: the post ID (numeric).
- For PDFs: filename stem.

## Renaming / merging pages

When the LLM determines two pages are duplicates:

1. Pick the canonical name (older, or more specific, or matching the most recent source).
2. Move all content to the canonical page.
3. Replace the other page's content with:
   ```yaml
   ---
   title: "Other Name"
   kind: redirect
   superseded_by: "[[Canonical Name]]"
   lifecycle: superseded
   ---
   This page has moved to [[Canonical Name]].
   ```
4. Run `cross-linker` to update incoming `[[Other Name]]` references.

Never delete a page outright — always leave a redirect stub so historic logs/sources resolve.
