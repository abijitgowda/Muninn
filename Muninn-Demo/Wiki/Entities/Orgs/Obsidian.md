Obsidian is a knowledge management application developed by Shida Li and Erica Xu, launched in 2020, that has become the tool of choice for practitioners of networked note-taking methodologies like [[Zettelkasten]] and [[Tiago Forte]]'s [[Second Brain]]. The application stores notes as plain markdown files in a local folder (called a "vault"), uses `[[wikilinks]]` for bidirectional linking between notes, and provides a graph view that visualizes the network of connections across the knowledge base. Its local-first architecture — where all data lives on the user's filesystem rather than in the cloud — aligns with privacy-conscious users and makes it an ideal viewing layer for AI-maintained knowledge systems.

Obsidian's extensibility through a rich plugin ecosystem has been central to its adoption. Community plugins add capabilities ranging from [[Spaced Repetition]] flashcards and Kanban boards to Dataview (a query language for note metadata) and Excalidraw (visual diagramming). The Copilot plugin integrates LLM capabilities directly into the editor. This plugin architecture means Obsidian can serve as the frontend for systems like [[Muninn]], which maintains wiki pages programmatically while the user browses and queries them through Obsidian's interface. The combination of plain-markdown storage and wikilink conventions makes Obsidian vaults naturally compatible with the [[LLM Wiki]] pattern.

The company operates on a freemium model: the core desktop application is free, with revenue coming from Obsidian Sync (end-to-end encrypted cloud sync) and Obsidian Publish (web publishing). Despite competition from Notion, Roam Research, and Logseq, Obsidian has built a loyal community that values data ownership, offline access, and the principle that notes should outlast any single application. Its role in the [[Personal Knowledge Management]] ecosystem positions it as the interface layer between human users and the AI-maintained knowledge graphs that represent the next evolution of note-taking.
