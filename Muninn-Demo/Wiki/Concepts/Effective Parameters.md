# Effective Parameters

Effective parameters refer to the active parameter count in models like Gemma4's E2B and E4B variants, which are tailored for edge device deployments. These models achieve comparable performance to larger counterparts by optimizing parameter usage through techniques such as parameter sharing and selective activation, enabling efficient on-device inference with reduced memory footprint while maintaining robust multimodal capabilities.
