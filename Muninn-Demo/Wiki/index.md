# Wiki Index

## Concepts
<!-- BEGIN: concepts -->
- [[Agent Framework]] — Software architectures that enable LLMs to autonomously plan, use tools, and execute multi-step workflows beyond simple prompt-response interactions.
- [[Agentic Workflows]] — Multi-step task execution patterns where LLM-powered agents plan, reason, and use tools autonomously to accomplish complex goals.
- [[Attention Mechanism]] — A neural network component that allows models to dynamically weight the relevance of different parts of an input sequence when producing each output element.
- [[Context Window]] — The maximum number of tokens a language model can process in a single forward pass, defining the boundary of what it can 'see' at once.
- [[Effective Parameters]] — The subset of a model's total parameters that are active during a single forward pass, particularly relevant for Mixture of Experts architectures.
- [[Fine-tuning]] — The process of adapting a pre-trained language model to a specific task or domain by training it further on a targeted dataset.
- [[GPU Computing]] — The use of graphics processing units for general-purpose parallel computation, the dominant hardware paradigm for training and running AI models.
- [[LLM Wiki]] — A persistent, interlinked knowledge base maintained by large language models, proposed by Andrej Karpathy as an alternative to repeated RAG queries.
- [[Mixture of Experts (MoE)]] — A neural network architecture that routes each input to a subset of specialized sub-networks (experts), enabling larger total capacity with lower per-inference compute.
- [[Multimodal Understanding]] — The ability of AI models to process and reason across multiple modalities including text, images, audio, and video.
- [[Retrieval Augmented Generation]] — A technique that augments LLM generation with relevant documents retrieved from an external corpus at query time.
- [[Retrieval-Augmented Generation (RAG)]] — Extended entry covering RAG implementations, vector databases, and hybrid search techniques.
- [[Second Brain]] — A methodology for externalizing knowledge into a trusted digital system that captures, organizes, distills, and expresses personal information.
- [[Spaced Repetition]] — A learning technique that schedules review of material at increasing intervals to exploit the spacing effect and maximize long-term retention.
- [[Spreading Activation]] — A brain-inspired retrieval mechanism where activating one node in a knowledge graph propagates activation to connected nodes through link traversal.
- [[Transformer Architecture]] — The dominant neural network architecture for sequence modeling, introduced in 2017, that relies entirely on self-attention mechanisms rather than recurrence.
- [[Zettelkasten]] — A note-taking method based on atomic, uniquely addressed, densely interlinked slips of paper (or digital notes), pioneered by sociologist Niklas Luhmann.
<!-- END: concepts -->
